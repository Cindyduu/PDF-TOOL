====================================================
  PDF 自动设置工具  使用说明
====================================================

版本：4.3（2026-11-12）
适用系统：Windows 10 / Windows 11（64 位）

----------------------------------------------------
一、这个工具是干什么的
----------------------------------------------------
分两段：先「校验」（只看，不改文件），再「处理」（按规范改）。
处理完会自动再校验一遍，那一步关不掉。

【第一段：校验】上传后先逐项体检，共 12 项，
每项给一个结论：PASS / WARNING / FAIL / —（跳过）：

   1. 文件命名规范
   2. 文件大小
   3. 外部链接
   4. 页面方向
   5. 文本可提取性
   6. 批注与高亮
   7. 字体嵌入
      每一种字体都必须真的嵌在文件里，包括 Helvetica、Times、Courier
      这类阅读器自带的「标准 14 字体」——阅读器有字形不等于你的文件有。
      判定口径对齐 Acrobat：文件 → 属性 → 字体，字体名后面带
      「（嵌入字符集）」才算数。只写了字体文件条目、内容却是占位符的，
      一样报 FAIL。
  8. 目录
  9. 页码
 10. 书签与承前缩放
      先看有没有书签：
        · 有书签  → 逐条看跳转动作是不是「承前缩放」，不是就报 WARNING
                    并列出具体页号（与页数无关，≤5 页也照样查）
        · 无书签  → ≤5 页跳过这一项；>5 页报 WARNING「无书签」
      「适合页面」「适合宽度」这类没有缩放位，不算承前缩放。
  11. 初始视图
      查文档属性里三项是否等于规定值：
          导览标签 = 书签面板和页面
          页面布局 = 默认
          放大率   = 默认
  12. 元数据与安全
      查描述字段（标题/作者/主题/关键字等）和 XMP 元数据是否清空，
      以及文件是否带加密或权限密码。

校验完可以导出一份报告（HTML 文件），断网双击也能打开。

【第二段：处理】7 个复选框，默认勾前 5 个
（第 6、7 项不可逆，默认不勾，勾的时候会弹确认）：

   1. 书签属性（承前缩放）              书签和页面内链接都改成承前缩放
   2. 清除文档描述（标题/作者/主题/关键字）
   3. 初始视图与目标位置                上表三项设成规定值
   4. 内链颜色修正（改为蓝色 RGB 0,0,255）
   5. 安全属性与元数据（快速 Web 查看）
   6. 注释扁平化                        不可逆，默认不勾
   7. 清除高亮和批注                    不可逆，默认不勾
                                        只删高亮/批注/便签，
                                        链接、图章、表单域保留

处理完会给你一份新 PDF 下载，原文件不动。

----------------------------------------------------
二、怎么安装
----------------------------------------------------
不用安装，拷过去就能用。

  1. 把整个 PDFTool 文件夹复制到同事电脑上
  2. 建议放在本地磁盘，例如 D:\PDFTool
  3. 不要放在 OneDrive、微信文件夹、网络共享盘里
     （同步中的文件被占用，会导致处理失败）

【最重要的一条】
  不能只拷 PDFTool.exe 这一个文件！
  它必须和同目录的 _internal 文件夹在一起，
  少了 _internal 就启动不了。

  要拷的就是这一整个文件夹：
      PDFTool\
        ├─ PDFTool.exe            ← 双击这个
        ├─ _internal\             ← 必须一起拷
        ├─ licenses\
        ├─ THIRD-PARTY-LICENSES.txt
        └─ 使用说明.txt

  不需要装 Python，不需要装任何运行库。

----------------------------------------------------
三、怎么用
----------------------------------------------------
  1. 双击 PDFTool.exe
  2. 会弹出一个黑色命令行窗口（这是服务在运行，正常现象）
     同时浏览器会自动打开网页
  3. 在网页里：选择 PDF 文件 → 勾要跑哪些校验项 → 开始校验
     → 看校验结果（可以导出报告）→ 进入自动处理 → 勾处理项
     → 开始处理
     不想校验也可以直接跳过：校验页底部有个复选框
     「不执行前置校验，直接进入自动处理」，勾上即可。
  4. 处理完成后点「下载」，会先弹出一个面板让你确认文件名，
     点「保存」后再选保存位置（详见第四节）
  5. 用完直接关掉那个黑色窗口，服务就停止了

  如果浏览器没有自动打开：
     手动打开浏览器，地址栏输入   http://127.0.0.1:8765

  可以一次选多个 PDF（最多 20 个），每个文件单独处理。
  全部处理完后，批量页上有「全部下载」按钮，可以一次把所有
  已完成的文件都下载下来（浏览器可能会问「是否允许下载多个
  文件」，点允许即可）。

----------------------------------------------------
四、下载时怎么改名字、选保存位置
----------------------------------------------------
  点结果页的「下载」按钮后，会先弹出一个小面板：

      【保存处理后的 PDF】
      原文件：  xxx.pdf
      大小：    1.2 MB
      文件名：  [xxx_已处理_20261106-101530_1aba21.pdf]
      点「保存」会弹出系统窗口，可以选择保存位置。
                [ 保存 ]        [ 取消 ]

  1. 文件名框里已经填好默认名字，而且是全选状态——
     想改名直接打字覆盖，不用先手动删。

  2. 点「保存」之后分两种情况：

     用 Chrome / Edge / 360 极速模式
        弹出系统的「另存为」窗口，保存位置和文件名一次选定，
        想存到 D 盘、桌面还是 U 盘都行。

     用其他浏览器（例如 Firefox）
        不弹窗口，文件直接存到浏览器的默认下载目录，
        但文件名仍然是你在面板里填的那个。

     面板上会提前写清楚是哪种情况，不会让你以为能选位置却选不了。

  3. 名字可以怎么改：

     会自动帮你修正（并在面板上提示改了什么）
        · 忘了写 .pdf              → 自动补上
        · 写成 报告.doc            → 改成 报告.pdf
        · 首尾多了空格             → 自动去掉

     会直接拒绝（保存按钮变灰，并说明具体原因）
        · 空名字
        · 带 / \ 这类路径分隔符
        · 带 < > : " | ? * 这些 Windows 不允许的字符
        · 用了 CON、PRN、COM1 这类 Windows 保留名
        · 名字太长（主名超过 150 个字）

     为什么不允许就直接拒绝、而不是自动换成下划线：
     那样你看着像改成功了，实际存下来是另一个名字，
     事后在文件夹里找不到。

  4. 点「取消」或者按 Esc，什么都不会下载。

  注意：批量页和历史记录页的下载按钮不弹这个面板，是直接下载
  （文件名由程序生成）。要改名请到单个文件的结果页点「下载」。

----------------------------------------------------
五、数据存在哪里
----------------------------------------------------
第一次运行后，文件夹里会自动多出一个 var 目录，
里面存着：

  - 你上传的 PDF
  - 处理好的结果
  - 历史记录和配置
  - 运行日志

想备份或者换电脑，把整个文件夹（含 var）拷走即可，
历史记录会一起带过去。

想彻底清空，删掉 var 目录就行，下次运行会重新生成。

六、常见问题
----------------------------------------------------

【1】Windows 提示「Windows 已保护你的电脑」
     或者杀毒软件报警 / 文件被删

   原因：这个程序没有购买数字签名证书，属于未签名程序，
         Windows 和杀毒软件对这类程序会谨慎提示。

   处理：
     - 弹出蓝色窗口时，点「更多信息」→「仍要运行」
     - 如果文件被 Defender 隔离了，到
       「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」
       里恢复，并添加排除项
     - 公司电脑如果装了企业管控软件，可能需要找 IT 加白名单

【2】提示端口被占用

   程序会自动往后找空闲端口（8766、8767……），
   具体地址看黑色窗口里打印的那行「正在启动：http://...」。

   也可以自己指定端口，在命令行里运行：
       PDFTool.exe --port 9000

【3】浏览器打开是空白页 / 无法访问

   - 等 2～3 秒再刷新，服务启动需要一点时间
   - 确认黑色窗口没有被关掉
   - 确认地址是 http://127.0.0.1:8765 开头（不要用 https）

【4】处理大文件很慢

   正常。几百页的 PDF 需要几十秒到几分钟，
   窗口里会显示进度，不要重复点击。

【5】处理时报「有数字签名」被拒绝

   带数字签名的 PDF 一旦修改，签名就会失效。
   工具默认拒绝处理，请使用无签名的副本。

【6】关掉黑色窗口后，网页就打不开了

   这是正常的。这个工具是「窗口开着才能用」的本机服务，
   不是后台常驻程序。

【7】点「保存」后没有弹出选择位置的窗口

   说明当前浏览器不支持这个能力（例如 Firefox），
   文件已经按你填的名字存到浏览器的默认下载目录了。
   想自己选位置，请用 Chrome、Edge 或 360 极速模式打开。

【8】改了名字，存下来还是原来的名字

   确认你点的是结果页的「下载」按钮。批量页和历史记录页的
   下载是直接下载，不经过改名面板。

【9】点「全部下载」后只下了一个文件

   浏览器拦截了后续下载。地址栏右侧会有一个提示，
   点开选「始终允许」再点一次即可。

----------------------------------------------------
七、几点说明
----------------------------------------------------
  · 只在本机使用。服务只监听 127.0.0.1，
    同一个局域网里的其他人访问不到。

  · 处理是本地完成的，文件不会上传到任何服务器。

  · 处理结果请自己抽查一下再提交，
    工具只按规则改，不能替你判断内容是否正确。

  · 第三方开源组件的许可声明见 THIRD-PARTY-LICENSES.txt。
